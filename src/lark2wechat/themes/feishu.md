# feishu

复刻飞书文档（Docx）阅读视图的排版。飞书蓝强调、深灰文字、浅灰块底、彩色高亮块，现代、克制、工具感强。

参数基于飞书 / Lark 公开设计系统：品牌蓝 `#3370ff`、标题 `#1f2329`、正文 `#33373d`、边框 `#dee0e3`、浅底 `#f5f6f7`。

> **关于「1:1」**：飞书文档是前端动态渲染（CSS 类名 + JS），无法像公众号那样扒到 inline style，
> 所以本主题是「基于设计规范的高度接近版」。若要像素级 1:1，请提供一个飞书文档截图或导出样例，
> 我据图精调色值与字号。正文用 15px（适配公众号阅读；飞书原文为 14px，可改回）。

适合：产品 / 工具向内容、技术文档、希望与飞书文档观感一致的发布。
